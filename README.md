# Cyclone Impact Forecaster

AI-powered disaster decision-support system designed to predict
cyclone-related impacts and infrastructure vulnerability before
landfall.

## Project Pipeline

Observe
↓
Predict
↓
Understand
↓
Act
↕
Human Feedback

## Main Features

- Cyclone trajectory visualization
- Time-dependent impact visualization
- Flood and storm-surge risk
- Disaster-aware routing
- Route degradation over time
- Infrastructure dependency analysis
- Personalized preparedness
- Human-in-the-loop feedback
